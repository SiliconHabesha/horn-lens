# Übersetzung der App (Deutsch, Englisch, Tigrinya)

Semay gibt es auf Deutsch, Englisch und Tigrinya. Deutsch ist der Ausgangstext im Code.

## Regeln

1. Jeder sichtbare Text (auch accessibilityLabel, accessibilityHint, placeholder, Toast, Alert-Texte, Teilen-Texte, Stack-Titel) läuft durch `t()` aus `src/lib/i18n.ts`:
   ```ts
   import { t } from "../lib/i18n";
   <T>{t("Keine Meldungen in diesem Zeitraum.")}</T>
   ```
   Der deutsche Text ist der Schlüssel. Nichts umformulieren, nur einwickeln. Ausnahme: Sätze, die aus Teilen zusammengesetzt werden, werden zu einer Vorlage mit Platzhaltern, damit jede Sprache ihre eigene Wortstellung hat:
   ```ts
   // vorher: `${plural(n, "Behauptung", "Behauptungen")} geändert ${since}`
   t("{count} geändert {since}", { count: plural(n, "Behauptung", "Behauptungen"), since })
   ```
2. `t()` muss **beim Zeichnen** aufgerufen werden, nicht beim Laden der Datei (die Sprache kann wechseln). Konstanten auf Modulebene mit Texten: die deutschen Texte stehen lassen und erst bei der Anzeige `t(x)` aufrufen, oder die Konstante in eine Funktion verwandeln.
3. `plural(n, eins, viele)` übersetzt beide Wörter selbst. Die Wörter müssen im Wörterbuch stehen (Einzahl und Mehrzahl als eigene Schlüssel).
4. Datum und Zahlen kommen aus `src/lib/de.ts` (`fmtWhen`, `fmtDay`, `num` …) und sind schon sprachabhängig. Kein „Uhr“ selbst anhängen: `t("{time} Uhr", { time })` (englisch und Tigrinya ohne „Uhr“).
5. Nicht übersetzen: Eigennamen von Medien und Diensten (NASA FIRMS, UKMTO, USGS, IODA, BELES, Semay), Inhalte aus der Datenbank (Schlagzeilen, Behauptungen: das macht die Datenschicht), Code-Bezeichner, Kommentare.
6. Die Übersetzungen kommen in die eigene Datei `src/i18n/parts/<teil>.json`:
   ```json
   { "en": { "Deutscher Text": "English text" }, "ti": { "Deutscher Text": "ትግርኛ ጽሑፍ" } }
   ```
   Platzhalter `{name}` in allen Sprachen unverändert übernehmen. Jeder Schlüssel, den die eigenen Dateien mit `t()` oder `plural()` benutzen, muss in `en` und `ti` stehen (auch wenn er schon in einem anderen Teil steht).

## Ton

- Englisch: britische Schreibweise, sachlich, kurz, wie eine Nachrichtenagentur. Sentence case. „Lage“ = „Situation“, „Meldung“ = „Report“, „Behauptung“ = „Claim“, „Quellenart“ = „Source type“, „Hitzepunkt“ = „Heat spot“, „Vorfall auf See“ = „Incident at sea“, „Rückgang der Internetverbindung“ = „Internet connectivity drop“, „Stufe“ (einer Behauptung) = „Rating“, „Messwerte“ = „Measurements“, „Merken“ = „Save“, „Gemerkt“ = „Saved“.
- Tigrinya: Hochsprache, wie sie in Eritrea und Tigray geschrieben wird, Ge'ez-Schrift, keine amharischen Formen. Neutral, ohne Wertung, kurz. Feste Begriffe:
  Verbindliche Begriffe (nur diese benutzen):
  - Behauptung = ዝተባህለ (Mehrzahl ዝተባህሉ), Reiter „Behauptungen“ = ዝተባህሉ
  - Lage = ኩነታት
  - Meldung = ጸብጻብ, Meldungen = ጸብጻባት
  - Karte = ካርታ
  - Quelle = ምንጪ, Quellen = ምንጭታት, Quellenart = ዓይነት ምንጪ
  - Medium = ማዕከን ዜና, Medien = ማዕከናት ዜና
  - Hitzepunkt = ነጥቢ ሙቐት, Hitzepunkte = ነጥብታት ሙቐት
  - Erdbeben = ምንቕጥቃጥ ምድሪ
  - Vorfall auf See = ፍጻመ ኣብ ባሕሪ, Rotes Meer = ቀይሕ ባሕሪ
  - Internetverbindung = ምትእስሳር ኢንተርነት
  - Satellitenbild = ስእሊ ሳተላይት, Satellit = ሳተላይት
  - Ort = ቦታ, Orte = ቦታታት
  - Suchen = ድለ, Mehr = ተወሳኺ, Zurück = ተመለስ
  - neu = ሓድሽ, gestern = ትማሊ, heute = ሎሚ
  - Bestätigt = ዝተረጋገጸ, Wahrscheinlich = ክኸውን ዝኽእል, Unbestätigt = ዘይተረጋገጸ, Umstritten = ዘካትዕ, Falsch = ሓሶት
  - Regierung Eritreas = መንግስቲ ኤርትራ, Regierung Äthiopiens = መንግስቲ ኢትዮጵያ, Tigray = ትግራይ, Afar = ዓፋር, Eritrea = ኤርትራ, Äthiopien = ኢትዮጵያ
  - Merken = ዓቅብ, Gemerkt = ዝተዓቀቡ, Teilen = ኣካፍል
  - Stand (Zeit) = ኩነታት ናይ / ብ, kurz: „Stand {time}“ = „{time} ዝተሓደሰ“
- Wo Tigrinya unsicher ist, kurz und einfach formulieren statt blumig.

## Prüfen

`npx tsc --noEmit` im Ordner `app` muss ohne Fehler durchlaufen. Danach `node scripts/i18n-check.mjs` (meldet `t("…")`-Schlüssel ohne Übersetzung).
