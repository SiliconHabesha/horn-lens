# Marke Semay

Zeichen: zwei Klammern um einen Punkt in einer hochkant stehenden Linse. Der Punkt ist die Angabe, die Klammern sind ihr Zusammenhang (wer sagt es, wann, mit welchem Beleg).

- `src/build.py` erzeugt aus einer Quelle alle Dateien: `svg/` (Zeichen, Wortmarke, App-Symbol), `png/` (Vorschaubilder) und die Symbole der App (`app/assets/…`, `app/public/…`). Aufruf: `python3 src/build.py` (braucht Playwright und fontTools).
- Gleiche Geometrie in der App: `app/src/components/Logo.tsx`.
- Farben: Tiefsee #13262E, Gischt #EDF0EE, Lagune #0F6E74 (hell #4FB3B5), Nacht #0E1A1F. Schrift: Schibsted Grotesk.
- Das vollständige Markenhandbuch liegt als Design-System-Seite in Claude.
